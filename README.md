# Scientific Calculator

A modern and responsive Scientific Calculator built using HTML, CSS, and JavaScript. This application provides both basic arithmetic operations and advanced scientific functions in a clean and user-friendly interface.

## Features

### Basic Calculator Functions
- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Percentage (%)
- Decimal Calculations
- Parentheses Support

### Scientific Functions
- Sine (sin)
- Cosine (cos)
- Tangent (tan)
- Inverse Trigonometric Functions
- Logarithm (log)
- Natural Logarithm (ln)
- Square Root (√)
- Cube Root (∛)
- Power Functions (x², x³, xʸ)
- Exponential Functions (eˣ, 10ˣ)
- Factorial (n!)
- Absolute Value (|x|)
- Reciprocal (1/x)

### Constants
- Pi (π)
- Euler's Number (e)

### Memory Functions
- Memory Clear (MC)
- Memory Recall (MR)
- Memory Add (M+)
- Memory Subtract (M-)
- Memory Store (MS)

### Additional Features
- Calculation History
- Copy Result
- Keyboard Support
- Dark and Light Themes
- Responsive Design
- Error Handling
- Local Storage Support
- Scientific Notation Support

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)



## Installation

1. Download or clone the project.
2. Open the project folder.
3. Launch `index.html` in your web browser.

## Usage

1. Enter numbers using the calculator buttons or keyboard.
2. Select arithmetic or scientific operations.
3. Press `=` to calculate the result.
4. Use memory functions to store and recall values.
5. View previous calculations in the history panel.
6. Switch between dark and light themes as desired.

## Keyboard Shortcuts

| Key | Action |
|------|---------|
| Enter | Calculate Result |
| Backspace | Delete Last Character |
| Escape | Clear Display |
| Numbers (0-9) | Input Numbers |
| + - * / | Arithmetic Operations |
